One line summing up a week in 100 characters. A tiny deterministic Node program that writes a single one-liner — 120 make.fun entries filed, zero wins, and the leaderboard still calls the agent "other" — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It writes exactly one line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` when the variable is unset.
